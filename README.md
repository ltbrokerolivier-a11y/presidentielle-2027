# Présidentielle 2027 : les candidats

Site d'information neutre sur les candidats à l'élection présidentielle française de 2027.

- `index.html` : la page du site (elle lit `data/candidats.json`)
- `data/candidats.json` : toutes les informations (candidats, propositions, sources, calendrier, actualités)
- `scripts/build.py` : vérifie les données et fabrique un aperçu hors ligne `docs/index.html`
- `MISE_A_JOUR.md` : la procédure de mise à jour quotidienne

Publication : GitHub Pages, branche `main`, dossier racine.
